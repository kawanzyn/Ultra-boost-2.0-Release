# Setup

This repository contains the public, keyless Basic standalone script: UltraBoost.lua.

Load it from the raw file using the command in README.md, or copy the complete file into a compatible client context.

Controls:
1. Ultra: simplifies and locally hides eligible environmental objects.
2. Equilibrado: applies a white appearance to supported environment parts.
3. Leve: simplifies materials and hides supported texture maps.
4. Environmental collision: separate local option, off by default.
5. FPS monitor: local Heartbeat estimate.
6. Restore Original: restores captured visual and collision properties.
7. Drag the title or floating UB button to move the panel.

The ground, characters and gameplay-classified objects are protected heuristically. Client-side collision changes may be overridden by server authority.
