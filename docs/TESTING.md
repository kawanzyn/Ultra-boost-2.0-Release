# Basic validation checklist

- [ ] Compile UltraBoost.lua.
- [ ] Test Ultra, Equilibrado and Leve independently.
- [ ] Toggle texture/decal hiding and restore.
- [ ] Verify SurfaceAppearance maps restore.
- [ ] Test independent collision toggle and restoration.
- [ ] Verify ground remains visible and collision protected.
- [ ] Verify player/NPC/tool/gameplay protections.
- [ ] Add new map objects while a mode is active.
- [ ] Test panel and floating button with touch and mouse.
- [ ] Compare FPS in the same scene and camera position before/after.
- [ ] Record device, client and runtime versions.

A code compilation check does not prove runtime compatibility or a performance gain.
